# BarFold

轻量的原生 macOS 菜单栏管理器。把不常用的图标折叠起来，需要时展开；使用图标面板快速定位和打开原菜单。

支持 macOS 14 及以上。Swift / AppKit / SwiftUI 实现，无第三方包依赖。本项目为独立实现，不包含 iBar 的程序、资源、脚本或反编译代码。

## 使用

1. 运行 `BarFold.app`，首次会打开设置，菜单栏出现箭头和实线分界符 `│`。
2. 按住 **Command**，把想折叠的图标拖到实线左侧。也可在“整理全部”模式里右键面板图标，选择移动分区。
3. 点击箭头展开 / 折叠；右键打开设置和图标面板。默认快捷键 **Option + Command + B**。
4. 开启“始终隐藏”后，把图标拖到虚线 `┊` 左侧；这些图标仅在“整理全部”时显示。

图标顺序由 macOS 记住。自动收起可设为关闭、5、8、15 或 30 秒；设置窗口和图标面板打开时暂停。悬停展开、启动时折叠和登录启动均可在设置中启用。退出应用会移除本应用所有占位项。

首次设置时先保持全部展开。实线应在箭头左侧，虚线应在实线左侧；如果曾手动移动分界符，可在“整理全部”时按住 Command 调整回该顺序。其他菜单栏管理器可能仍会隐藏图标；请避免同时管理同一组图标。

## 图标面板与权限

- **无需额外权限**：折叠、展开、手动 Command 拖动、快捷键、自动收起和设置。
- **辅助功能（可选）**：根据系统辅助功能树识别图标、点击原菜单、移动图标分区。只有点击“授权”时才请求。
- **屏幕录制（可选）**：仅对菜单栏单图标窗口生成缩略图，图片不落盘。未启用时展示所属应用的图标；界面会标为“应用图标”。

图标面板每次打开或手动刷新时重新采集；不持续录制屏幕。对屏幕外、已退出或已变化的项目拒绝发送坐标点击，提示先展开整理。系统固定图标可能不接受拖动。

macOS Tahoe 的部分图标由控制中心统一承载；辅助功能能提供名称时优先使用，无法识别时保留系统提供的名称。当前实现不使用 iBar 的 AppleScript、动态私有窗口 API 或虚拟显示方案。图标数量超过屏幕宽度时，基础展开受菜单栏可用宽度限制，不能保证每个离屏项目都可操作。

## 构建

安装 Apple Command Line Tools 与 Swift 5.9+，然后：

```sh
swift run BarFoldCoreChecks
bash scripts/build-app.sh
open dist/BarFold.app
```

产物为 `dist/BarFold.app`，按当前主机架构构建并进行 ad-hoc 签名。可复制到 `~/Applications` 或 `/Applications` 后使用。此构建没有 Developer ID 签名和 Apple 公证；登录启动以系统实际授权状态为准。

## 验证

```sh
swift run BarFoldCoreChecks
bash scripts/build-app.sh
bash scripts/smoke.sh
```

核心检查覆盖延迟回调失效、窗口暂停、分区几何、目标范围及配置保护。原生 smoke 必须在已登录的 macOS 图形桌面运行，会临时显示自己的测试状态项和两个窗口，并在退出时移除；使用独立 bundle ID 和配置路径，不读取生产配置。它不授予权限，也不点击其他应用。

GitHub Actions 执行核心检查和应用构建；原生交互验证单独记录在 [VERIFICATION.md](VERIFICATION.md)。测试构建不等同于权限功能已实测。

## 数据与实现

配置位于 `~/Library/Application Support/BarFold/config.json`。损坏或不支持版本的配置会保留，并停止覆盖写入。应用只写自己的配置、状态项位置和用户明确启用的登录项；不修改其他应用偏好或全局菜单栏间距。没有网络请求、分析统计、账号或订阅功能。

- `Sources/BarFoldCore`：折叠状态、代次检查、分区与配置。
- `Sources/BarFold`：菜单栏布局、界面、截图、辅助功能、鼠标操作与系统快捷键。
- `scripts`：可复现构建、图标生成、原生验证。

`--config /absolute/path.json` 可用于隔离配置测试，`--settings` 打开设置。菜单栏布局依赖 macOS；多屏、刘海及其他管理器共存需要结合实际环境验证。
